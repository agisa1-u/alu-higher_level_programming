# python-exceptions

Python exercises on exception handling (`try` / `except` / `finally` and `raise`), from the ALU Higher Level Programming curriculum.

All files are written for Python 3, start with `#!/usr/bin/python3`, are PEP8 (pycodestyle) compliant, and are executable.

## Tasks

| File | Description |
| --- | --- |
| `0-safe_print_list.py` | Prints x elements of a list and returns the real number printed |
| `1-safe_print_integer.py` | Prints an integer with `"{:d}".format()`, returns `True` or `False` |
| `2-safe_print_list_integers.py` | Prints the first x elements of a list, integers only, and counts them |
| `3-safe_print_division.py` | Divides 2 integers and prints the result in the `finally` section |
| `4-list_division.py` | Divides element by element 2 lists, handling wrong type, division by 0 and out of range |
| `5-raise_exception.py` | Raises a `TypeError` |
| `6-raise_exception_msg.py` | Raises a `NameError` with a message |
