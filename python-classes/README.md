# python-classes

Python exercises on classes and objects (private attributes, properties, validation), from the ALU Higher Level Programming curriculum. Each file builds on the previous one.

All files are written for Python 3, start with `#!/usr/bin/python3`, are PEP8 (pycodestyle) compliant, documented, and executable.

## Tasks

| File | Description |
| --- | --- |
| `0-square.py` | An empty class `Square` |
| `1-square.py` | `Square` with a private `size` attribute (no validation) |
| `2-square.py` | Adds `size` validation (`TypeError` / `ValueError`) |
| `3-square.py` | Adds the public `area()` method |
| `4-square.py` | Adds a `size` property with getter and validating setter |
| `5-square.py` | Adds `my_print()` to print the square with `#` |
| `6-square.py` | Adds a validated `position` property used by `my_print()` |
