The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class:

    >>> MyList = __import__('1-my_list').MyList

It is a list:

    >>> issubclass(MyList, list)
    True

Sorted print of an unsorted list (the list itself is not modified):

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Empty list:

    >>> MyList().print_sorted()
    []

Already sorted list:

    >>> my_list = MyList([1, 2, 3])
    >>> my_list.print_sorted()
    [1, 2, 3]

Reverse sorted list:

    >>> my_list = MyList([3, 2, 1])
    >>> my_list.print_sorted()
    [1, 2, 3]

Negative numbers and duplicates:

    >>> my_list = MyList([5, -1, 3, -1, 0, 5])
    >>> my_list.print_sorted()
    [-1, -1, 0, 3, 5, 5]
    >>> print(my_list)
    [5, -1, 3, -1, 0, 5]

A single element:

    >>> my_list = MyList([42])
    >>> my_list.print_sorted()
    [42]

Instantiating from another iterable:

    >>> my_list = MyList((9, 7, 8))
    >>> my_list.print_sorted()
    [7, 8, 9]

``print_sorted`` takes no argument:

    >>> MyList([1]).print_sorted(1)  # doctest: +ELLIPSIS
    Traceback (most recent call last):
    ...
    TypeError: ...print_sorted() takes 1 positional argument but 2 were given
