# python-more_classes

Python exercises on classes and objects (private attributes, properties, class attributes, static and class methods, special methods), from the ALU Higher Level Programming curriculum. Each file builds on the previous one.

All files are written for Python 3, start with `#!/usr/bin/python3`, are PEP8 (pycodestyle) compliant, documented, and executable.

## Tasks

| File | Description |
| --- | --- |
| `0-rectangle.py` | An empty class `Rectangle` |
| `1-rectangle.py` | Private `width` / `height` with validating properties |
| `2-rectangle.py` | Adds `area()` and `perimeter()` |
| `3-rectangle.py` | Adds `__str__` to draw the rectangle with `#` |
| `4-rectangle.py` | Adds `__repr__` so `eval(repr(rect))` recreates the instance |
| `5-rectangle.py` | Prints `Bye rectangle...` when an instance is deleted |
| `6-rectangle.py` | Adds the public class attribute `number_of_instances` |
| `7-rectangle.py` | Adds the public class attribute `print_symbol` (any type) |
| `8-rectangle.py` | Adds the static method `bigger_or_equal()` |
| `9-rectangle.py` | Adds the class method `square()` |
